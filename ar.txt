library_asset_app/

├── config.py             ← DB credentials + colour palette + fonts

├── ui_helpers.py         ← Shared widget factories (lbl, btn, entry, make_treeview …)

├── app.py                ← Root App window, sidebar, nav routing

    ├── __init__.py       ← Re-exports all frame classes cleanly
    ├── dashboard.py      ← DashboardFrame (KPI cards)
    ├── members.py        ← MembersFrame + MemberDialog
    ├── library.py        ← LibraryFrame + BookDialog + IssueBookDialog
    ├── assets.py         ← AssetFrame + AssetDialog + AssignAssetDialog
    └── settings.py       ← SettingsFrame
